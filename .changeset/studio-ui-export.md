---
"@typren/studio": minor
---

Adds `@typren/studio/ui`, the studio's primitives (Button, Input, Select, Dialog, Menu, Card, Avatar, Skeleton, Sheet, TopBarButton and more) for a host app that must look like the studio, and `@typren/studio/tokens.css`, which loads core's `--typren-*` tokens plus shadcn-name aliases onto them so utility classes like `bg-background` resolve to studio tokens. `MediaGrid` takes an optional `extraActions` prop for per-asset host actions beside Copy and Delete.
