# 0.5.x promotion review

## How this review was done

1. **Whole-repository review at 7183f4e** (`method: workflow`). The `security-review` workflow ran four lenses plus a red team, and two skeptics checked every finding. Of 34 findings, 34 were confirmed: 0 critical, 2 high, 9 medium and 23 low. Outcome at that commit: **fail**.
2. **Fixes on `fix/review-0.5.0`.** Every high and medium finding was fixed, one concern per commit, each with a regression test.
3. **Focused adversarial re-review of the fix diff (7183f4e..87132c8).** Two Opus reviewers worked read-only with repro scripts:
   - one on auth, localAuth, Notion and YAML;
   - one on the release workflow, the publish script and the review gate.
   They confirmed every original high and medium as fixed. They found four new issues (one medium, three low), and several low hardening gaps in the release path. All of those are fixed in 2e994f8..1bc0587, and the maintainer checked those fixes against the reviewers' repro scripts.
4. **Verification.** `bun run verify` passes at this head.

The release ships as core 0.5.1. 0.5.0 was versioned on develop but never published.

## Fixed (confirmed at 7183f4e)

| Severity | Finding | Fix |
|---|---|---|
| high | `clerkAuthAdapter` trusted `org_role` without binding it to an organization; the admin path skipped the allowlist | `organizationId` is required with roles and checked against v1 `org_id` or v2 `o.id`; admin runs after the base allowlist |
| high | The OIDC publish job installed `@changesets/cli` with unpinned transitive dependencies | `scripts/publish-unpublished.mjs` (stdlib only) replaces `changeset publish`; nothing is resolved in the publish job |
| medium | Notion code block nested in a list broke out of its fence | Every code line now carries the container indent |
| medium | Notion text and captions could inject markdown links with any scheme | Markdown metacharacter and line-leading marker escaping; the existing `safeUrl` is reused |
| medium | localAuth trusted the Host header | Allows only when Next's own bind origin is `127.0.0.1`; Host is a deny filter only |
| medium | `typren init` didn't write the loopback-bound dev script the docs promise | The scaffold binds `next dev -H 127.0.0.1` |
| medium | nextAuth email allowlists had no verified-email signal | `isEmailVerified` callback, required with `allowedEmails` |
| medium | Release artifact not limited to `dist/` | Publish job downloads to a temp dir and copies only `packages/*/dist` and core `migrations/`; symlinks are refused |
| medium (x2) | Gate sensitive list missed build config, tests and shipped notes | All root files, `packages/**`, `apps/**`, `.github/**`, `.changeset/**`, `docs/migrations/**` are sensitive; renames count as both paths |
| medium | Serializer wrote YAML anchors and had no size cap, so a page could become unreadable | `stringifyMatter`: `noRefs`, a read-back through `parseMatter`, the 256 KB cap |
