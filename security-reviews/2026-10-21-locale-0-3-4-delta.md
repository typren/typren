## Verified clean

- The re-exec spawns `process.execPath` with an argv array and no shell, adds only `NODE_USE_ENV_PROXY=1` to the
  environment, never loops (the child always sees the flag), and treats any explicit value of the flag as an opt-out.
- `NO_PROXY` is honored. HTTPS goes through a CONNECT tunnel, so the proxy never sees the API token, which is the
  same exposure the vendor CLI has. `assertBundleOrigin` and `redirect: "manual"` still apply to every bundle URL.
- The lazy purifier fails closed: if jsdom cannot load, purification throws instead of passing content through, and
  both callers purify before anything is written or used.
- `ci.yml` keeps a plain `pull_request` trigger with `contents: read` and no secrets. checkout, setup-node and
  setup-bun are pinned by SHA, and no cache is restored. actionlint is downloaded over HTTPS, its sha256 is checked
  before extraction, and only the binary is extracted. The aggregate `CI` job fails unless the whole matrix succeeded.
- `scripts/check-workflows.mjs` runs actionlint with no arguments, input or shell. It warns when actionlint is missing
  locally and fails when `CI` is set.
