## Why waived

`npx typren@0.5.1 migrate` fails on every project ("Package subpath './package.json' is not defined by exports"),
and the published deprecation messages and the pending advisory tell users to run it. Holding 0.5.2 for a full
review keeps that broken path live.

The delta since the last review (`2026-10-15-0-5-1-release-artifact.md`, be6a1d8) is PR #113 plus Version
Packages. Its content is fixes for findings already raised by the 0.5.x review and tracked in #105. Each fix was
reviewed at the diff level before merge, and `bun run verify` and CI passed. What it adds to the public API is
additive and optional: `localAuth({ isBoundToLoopback })`, `AuthContext.collectionId`/`locale`,
`BuildRedirectsOptions.reservedPrefixes`, and an optional `request` argument to `FormSink.deliver`.
