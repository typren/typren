# Code of conduct

## The short version

Be decent. Assume good faith. Criticise code, not people.

This project adopts the [Contributor Covenant v2.1][cc], which is the long
version of the same idea and is worth reading if you want the specifics.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## What that means here

Expected:

- Welcoming, respectful language
- Accepting review feedback gracefully, and giving it kindly
- Focusing on what's best for the project rather than on being right

Not acceptable:

- Harassment, personal attacks, or discriminatory language of any kind
- Sexualised language or imagery, or unwelcome sexual attention
- Publishing others' private information without permission
- Sustained disruption of discussions

## Scope

Applies in all project spaces, including issues, pull requests and discussions, and when
representing the project publicly.

## Enforcement

Report to **mataleo.gml@gmail.com**. Reports are handled confidentially and
you'll get a response.

Maintainers may remove or reject any contribution that violates this document,
and may ban a contributor temporarily or permanently for behaviour they judge
inappropriate, threatening, or harmful.

Right now this project has a single maintainer, so a report about that
maintainer has nowhere independent to go. That's an honest limitation of a
one-person project rather than a policy. If it becomes a problem, raise it
publicly.
